# IITM BS Degree - Programming in C (CS3005) OPPE Practice Solutions

This repository contains my practice solutions and implementations for **Programming in C (CS3005)** under the **IIT Madras BS Degree Program**.

The programs included here are based on various **OPPE style coding questions**, pattern problems, number manipulation tasks, pointer-based functions, and fundamental C programming concepts frequently tested in assignments and programming exams.

---

### 1. Number Manipulation
- Digit rotation (left/right rotations)
- Largest digit extraction
- Digit-based transformations
- Counting digits in a number
- Reversing numbers
- Palindrome-related concepts
- Octal number literals and number systems

### 2. Loops and Iteration
- `for` loops
- `while` loops
- Nested loops
- Step-by-step number transformations
- Effective rotation calculation using modulo

### 3. Pattern Printing
- Palindrome Number Triangle
- Number pyramids
- Symmetric number patterns
- Nested loop pattern generation

### 4. Functions
- User-defined functions
- Function decomposition
- Parameter passing
- Return values
- Helper functions

### 5. Pointers
- Pointer parameters
- Updating values through pointers
- Passing variables by reference
- Pointer-based problem solving

### 6. Arrays and Input Handling
- Taking dynamic inputs using loops
- Reading integers based on user input count
- Basic array usage

### 7. Mathematical Logic
- Powers of 10
- Modulus (`%`) operations
- Integer division
- Digit extraction techniques

### 8. C Language Fundamentals
- Variable declarations
- Integer data types
- Conditional statements (`if`, `else if`, `else`)
- Operators
- Input/Output using `scanf()` and `printf()`
